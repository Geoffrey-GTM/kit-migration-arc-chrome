# Code de conduite

## Notre engagement

Nous voulons que la participation à ce projet soit une expérience accueillante et respectueuse pour tout le monde, quels que soient le niveau d'expérience, l'identité, l'origine ou les opinions de chacun.

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/). Le texte complet fait foi.

## En pratique

Ce que nous attendons de chacun :

- être bienveillant et patient, en particulier avec les personnes non techniques qui utilisent le kit ;
- critiquer les idées, pas les personnes ;
- accepter les retours constructifs et reconnaître ses erreurs ;
- protéger la vie privée des autres : ne jamais publier les données de navigation, les noms de clients ou les informations personnelles de quelqu'un d'autre.

Ce qui n'est pas accepté :

- le harcèlement, les insultes et les attaques personnelles ;
- les propos ou contenus discriminatoires ;
- la publication d'informations privées sans accord explicite.

## Signalement

Pour signaler un comportement inacceptable, utilise le signalement privé du dépôt : onglet **Security**, puis **Report a vulnerability**. Indique « Code de conduite » dans le titre.

Tous les signalements sont traités avec confidentialité. Le mainteneur peut retirer, modifier ou refuser toute contribution qui ne respecte pas ce code, et exclure temporairement ou définitivement les personnes concernées.
