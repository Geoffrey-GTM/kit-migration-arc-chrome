# Correspondance entre espaces Arc et profils Chrome (facultatif)
#
# Par défaut, en mode « un profil Chrome par espace », chaque espace Arc va
# dans le profil Chrome qui porte exactement le même nom (majuscules indifférentes).
#
# Ce fichier sert à :
#   - envoyer un espace vers un profil Chrome qui a un autre nom :
#         Nom de l'espace Arc = Nom du profil Chrome
#   - ne pas migrer un espace du tout (valable dans les deux modes) :
#         Nom de l'espace Arc = ignorer
#
# Une règle par ligne. Tout ce qui suit un # est un commentaire.
#
# Tu as cloné le dépôt avec Git ? Mets plutôt tes règles dans un fichier
# « correspondance.local.txt », à côté de celui-ci : il n'est jamais versionné,
# et ses règles l'emportent sur celles de ce fichier.
# Exemples (retire le # devant pour les activer) :
#
# Clients = Travail
# Ancien client = ignorer
